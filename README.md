
# ShopNow - Sistema de Balanceamento de Carga

## Sobre o projeto
O ShopNow é um projeto desenvolvido em Python para simular um sistema de distribuição de requisições entre múltiplos servidores.

## Tecnologias utilizadas
- Python
- Flask
- Requests
- Git e GitHub

## Estrutura
- app/server.py: implementação dos servidores.
- app/load_balancer.py: implementação do balanceador de carga.
- requirements.txt: dependências do projeto.

## Algoritmos
- Round Robin
- Least Connections

## Objetivo
Distribuir requisições entre diferentes instâncias de servidores, melhorando a disponibilidade e a capacidade de atendimento do sistema.
