
# Testes do ShopNow

## Objetivo
Verificar o funcionamento do balanceador de carga e das instâncias de servidores.

## Testes realizados
- Inicialização das instâncias de servidores.
- Verificação de disponibilidade dos servidores.
- Distribuição de requisições pelo algoritmo Round Robin.
- Distribuição de requisições pelo algoritmo Least Connections.
- Verificação do comportamento durante falhas de servidores.
- Simulação de múltiplas requisições.

## Resultado
Os testes devem ser executados para verificar a distribuição de requisições e a disponibilidade do sistema.
